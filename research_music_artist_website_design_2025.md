## 🔧 Implementation Guide

<implementation>
### Color Palette Strategy

**The Three-Color System:**
1. **Primary Color**: Genre-aligned (earth tones for Americana, vibrant for EDM, soothing for indie)
2. **Secondary Color**: Complementary to primary, supports brand mood
3. **Accent Color**: High contrast for text, buttons, and interactive elements

**Color Scheme Options:**
- **Monochromatic**: Different tones/shades of single color (simple, popular)
- **Analogous**: Three adjacent colors on color wheel (complex, harmonious)
- **Complementary**: Opposite colors for strong contrast effect

**2025 Palette Trends:**
- Bold minimalism with striking typography and subtle color accents
- Retro-inspired with neon accents and handcrafted elements
- Avoid pure white/black - use neutral tints for eye comfort
- Apply 60-30-10 rule: 60% primary, 30% secondary, 10% accent

### Typography Systems

**Hierarchy Structure:**
- H1 Headers: 48px (site title, main headings)
- Body Text: 16px (standard readable size)
- Subheadings: Between 16px-48px based on hierarchy

**Font Selection Rules:**
- One consistent content font throughout
- Creative display font for titles/section headers
- Maximum 2-3 fonts total to avoid clutter
- Left-align text for readability
- Use bold/italics sparingly
- Avoid all caps except for emphasis

### Component Design Patterns

**Essential UI Components:**
- Dynamic playlist/album covers with hover effects
- Responsive navigation with mobile hamburger menu
- Call-to-action buttons with high contrast colors
- Social media integration with consistent iconography
- Event calendar with clear date hierarchy
- Media player with intuitive controls
- Email signup forms with clear value proposition

**Layout Patterns:**
- Bento grids for flexible, responsive content arrangement
- Hero sections with large artist imagery and key messaging
- Two-column layouts for bio/content sections
- Gallery grids for photos/videos with consistent spacing
- Footer with organized links and contact information

### Modern Interactive Elements

**2025 Trends:**
- Interactive 3D elements for album art/merchandise
- Scroll animations revealing content step-by-step
- Dark mode interfaces (especially for gaming/electronic genres)
- Glassmorphism effects with translucent elements
- AI-driven content personalization based on user behavior
</implementation>

## ⚠️ Critical Considerations

<considerations>
### Performance Requirements
- **Load Times**: Under 2 seconds (47% of users expect this)
- **Mobile Optimization**: 64% of searches are mobile-first
- **Image Optimization**: Proper file formats, compression, lazy loading
- **Media Management**: Avoid auto-playing videos, optimize audio players

### Accessibility Standards
- **Color Contrast**: Use online contrast checkers for WCAG compliance
- **Font Readability**: Minimum 16px body text, clear hierarchy
- **Navigation**: Keyboard accessible, screen reader friendly
- **Alt Text**: All images need descriptive alt attributes

### Common Technical Pitfalls
- **Responsive Design**: Must work across all device sizes
- **Navigation Clarity**: Avoid haphazard menu organization
- **Content Overload**: Prevent text walls and cluttered interfaces
- **Stock Photos**: Use authentic, branded imagery instead of generic stock

### Security & Privacy
- **Data Protection**: Secure email collection and fan data
- **SSL Certificates**: HTTPS for all pages, especially e-commerce
- **Cookie Compliance**: Clear privacy policies and consent flows
</considerations>

## 🚫 Common Design Mistakes to Avoid

<mistakes>
### Visual Identity Errors
- **Inconsistent Branding**: Different visuals across platforms
- **Too Many Fonts**: Limit to 2-3 maximum for cohesion
- **Poor Color Choices**: Generic palettes that don't reflect genre
- **Stock Photo Overuse**: Lacks authenticity and brand connection

### User Experience Problems
- **Slow Loading**: Over 2-second load times drive users away
- **Non-Responsive Design**: Critical failure with 64% mobile traffic
- **Cluttered Interface**: Too much information overwhelms visitors
- **Poor Navigation**: Confusing menu structure frustrates users

### Content Issues
- **Text Walls**: Massive blocks intimidate and overwhelm visitors
- **Weak CTAs**: Unclear or poorly positioned call-to-action buttons
- **Auto-Playing Media**: Annoying and impacts page performance
- **Missing Essential Info**: Bio, contact, tour dates, music links

### Technical Problems
- **Unoptimized Images**: Large file sizes slow page loading
- **No Mobile Version**: Loses majority of potential audience
- **Broken Links**: Poor maintenance creates frustrated users
- **No Analytics**: Can't measure or improve performance
</mistakes>
