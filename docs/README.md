## Quick Start

Get your music website running in under 5 minutes:

```bash
# Clone the framework
git clone https://github.com/yourusername/lean-music-framework.git your-artist-name

# Navigate to your project
cd your-artist-name

# Install dependencies
npm install

# Start development
npm run dev
```

Visit `http://localhost:3000` and you'll see your new music website ready for customization!
